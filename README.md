# 🖧 Packet Tracer Network Architectures

A collection of advanced **Cisco Packet Tracer** network designs focused on real-world **enterprise architectures, routing, and network security**.

This repository showcases practical implementations of modern network infrastructures, combining routing protocols, VLAN segmentation, and security mechanisms.

---

## 🚀 Objectives

* Design scalable **enterprise-level network architectures**
* Implement **routing protocols** (OSPF, EIGRP, RIP)
* Apply **network segmentation using VLANs**
* Configure **network services** (DHCP, DNS, HTTP)
* Simulate **basic network security** (ACL, NAT, DMZ)

---

## 🧠 Technologies & Concepts

* Routing: OSPF (Single & Multi-Area), EIGRP, RIP
* Switching: VLANs, Trunking (802.1Q), STP
* IP Services: DHCP, DNS, NAT
* Security: ACL (Access Control Lists), Network Segmentation
* Network Design: Core–Distribution–Access Architecture
